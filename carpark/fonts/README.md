# Mercedes-Benz fonts

The car park page is set in the Mercedes-Benz corporate typefaces:

| Used for | Typeface |
| --- | --- |
| Everything (labels, search, info card) | MB Corpo S Text, Regular and Bold |
| Page title | MB Corpo A Title Cond, Regular |

The fonts are licensed by Mercedes-Benz to its partners, so they are not included here.
Until the files are added, a computer that has the fonts installed shows them, and every
other device (phones included) falls back to Helvetica/Arial.

To turn them on for every device, put the font files in this folder with these names
(`.woff2` preferred; `.woff`, `.ttf` and `.otf` also work, same names otherwise):

```
MBCorpoSText-Regular.woff2
MBCorpoSText-Bold.woff2
MBCorpoATitleCond-Regular.woff2
```

Note: this repository is public. Files added here can be downloaded by anyone, so check
that the font licence allows that before committing them, or host the page somewhere private.
